# Dr. Paul A. Stokes — Website Guide

Your website is live at **[https://pstokes.eu](https://pstokes.eu)**  
(also works with **[https://www.pstokes.eu](https://www.pstokes.eu)**)

This short guide explains how to use the site day to day. You do not need any technical knowledge.

| --- | --- |

## Managing your content (Admin Panel)

To add or edit papers, blogs, and access requests, open:

**[https://pstokes.eu/admin](https://pstokes.eu/admin)**

Bookmark this link so you can find it quickly.

At the top you will see three tabs:

1. **Papers** — Document Library items  
2. **Blogs** — Blog posts / articles  
3. **Access Request** — People asking for restricted papers  

Use **View Site** in the admin header anytime to open the public website.

---

## Papers (Document Library)

### Add a new paper

1. Open the **Papers** tab  
2. Click **Add New Paper**  
3. Fill in the main details:
   - **Full document title** (required)
   - Optional hero title, summary, and badge
   - Author name and affiliation
   - Content sections (title + text for each part of the paper page)
   - Category, publish date, and tags
4. Choose **Access**:
   - **Public** — anyone can download the PDF from the library  
   - **Restricted** — visitors must request access; you approve or reject later  
5. Upload:
   - A **cover thumbnail** (optional image for the card)
   - The **Paper PDF** (required for a downloadable document)
6. Click **Add Paper**

The paper appears on the **Library** page shortly after you save.

### Edit or remove a paper

- In **Your Papers**, click **Edit** to change details or replace the PDF/thumbnail  
- Click **Delete** to remove it (you will be asked to confirm)

### Tip for file names

If an upload fails with an “Invalid key” style message, rename the file to something simple (letters, numbers, hyphens) and try again. Spaces and special characters in file names can cause problems.

## Blogs

### Add a new blog post

1. Open the **Blogs** tab  
2. Click **Add New Blog Post**  
3. Fill in the title, summary, sections, cover image, and other fields  
4. Save the post  

It will appear on the **Blogs** page.

### Edit or remove a blog

Same as papers: use **Edit** or **Delete** in the list of your posts.

---

## Access requests (restricted papers)

When a visitor asks for a **Restricted** paper, their request shows up under **Access Request**.

For each pending request you will see:

- Their name and email  
- Which paper they want  
- Why they are asking  
- The date of the request  

### Approve

Click **Approve**.

- The person is emailed a link to download the paper  
- The request moves to **Approved**

### Reject

Click **Reject**.

- Access is denied  
- The request moves to **Rejected**

You can filter the list by **All**, **Pending**, **Approved**, or **Rejected**.

---

## Contact messages

People who use the **Contact** page send messages to your configured email inbox. Those are separate from the Access Request tab in admin.
